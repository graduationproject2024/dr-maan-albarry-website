- **BUG-03** (P1, Fixed) — Every simulator mount leaked one WebGL context (capability probe never released). Root cause: hasWebGL()/hasWebGL2() created a context on a throw-away canvas to test support and left it alive until garbage collection; browsers cap live contexts (~16) and then evict the oldest. Fix: Both probes release the probe context at once with WEBGL_lose_context.loseContext(). Regression test: tests/journey-regressions.spec.js › BUG-02/BUG-03 and BUG-03 (vision).

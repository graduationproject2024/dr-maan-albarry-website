Fix: When the button (or body) held focus, focus moves to the viewer's own Play control (preventScroll). Regression test: tests/journey-regressions.spec.js › BUG-06.
- **BUG-17** (P2, Fixed) — Accessible names did not contain the visible text (wordmark, "EN" language button). Root cause: aria-label overrides were written without the visible text. Fix: The wordmark uses its visible text plus a visually hidden "— home"; the button label starts with "EN". Regression test: tests/journey-regressions.spec.js › BUG-17; axe.spec.js.

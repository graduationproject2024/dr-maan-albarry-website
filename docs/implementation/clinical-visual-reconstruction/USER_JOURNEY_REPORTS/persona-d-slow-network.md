### Defects found

- **BUG-05** (P2, Fixed) — Layout shift on a slow first load at 320 px (CLS ≈ 0.26) when the web fonts arrive. Root cause: Fallback and web-font metrics differ; with font-display: swap the late swap re-wraps the hero text. Fix: Metric-matched fallback @font-face rules (size-adjust, ascent/descent-override) for Noto Sans Arabic, Readex Pro (Segoe UI), Public Sans (Arial) and Source Serif 4 (Times New Roman), regular and bold, measured in Chromium; inserted after each web font in the stacks. The brand fonts still load and swap in, now without re-wrapping. Retest: persona-d CLS 0.0002 (3 runs), J08 Slow 3G CLS 0 (was 0.17). Calibrated on Windows fonts; other platforms fall through to their previous fallbacks. Regression test: Journey step persona-d #2 (now a hard assertion: CLS < 0.1).
- **BUG-08** (P3, Fixed) — aria-busy was set to "" (= false) while the 3D code downloads. Root cause: toggleAttribute() writes an empty value; ARIA treats an empty value as the default (false). Fix: setAttribute("aria-busy", "true") / removeAttribute(). Regression test: tests/journey-regressions.spec.js › BUG-08.
- **BUG-14** (P3, Won't fix (by design)) — A 3D load abandoned on the cataract page appears later in the home page's 3D section. Root cause: By design the viewer is carried across pages that host #cataract-3d. Fix: Not changed — product decision; a single instance and no leak are verified. Regression test: Persona D steps 6–8.

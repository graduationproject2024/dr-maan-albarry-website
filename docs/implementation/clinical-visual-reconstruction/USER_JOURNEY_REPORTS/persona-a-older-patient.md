### Defects found

- **BUG-01** (P2, Fixed) — Procedure-page reading text below 16 px (anatomy terms, lens types, benefits/limitations, safety notes). Root cause: The secondary text token (--fs-small, 15 px) was used for core reading content, not only captions. Fix: Those four rules now use --fs-body (17 px AR / 16 px EN); captions and the sources box stay small. Regression test: tests/journey-regressions.spec.js › BUG-01 (ar, en).
- **BUG-02** (P2, Fixed) — 3D stage description text 15.5 px. Root cause: 0.97rem was chosen for density. Fix: 1rem. Regression test: tests/journey-regressions.spec.js › BUG-02/BUG-03.
- **BUG-03** (P1, Fixed) — Every simulator mount leaked one WebGL context (capability probe never released). Root cause: hasWebGL()/hasWebGL2() created a context on a throw-away canvas to test support and left it alive until garbage collection; browsers cap live contexts (~16) and then evict the oldest. Fix: Both probes release the probe context at once with WEBGL_lose_context.loseContext(). Regression test: tests/journey-regressions.spec.js › BUG-02/BUG-03 and BUG-03 (vision).
- **BUG-15** (P3, Fixed) — Touch targets under 44 px: header wordmark (39 px tall), breadcrumb "Home" (42 px wide), footer links (40 px tall). Root cause: min-height 40 px in the footer; no minimum size on the wordmark or breadcrumb links. Fix: min-height 44 px (and min-width 44 px for breadcrumb links). Regression test: Persona A step 13.

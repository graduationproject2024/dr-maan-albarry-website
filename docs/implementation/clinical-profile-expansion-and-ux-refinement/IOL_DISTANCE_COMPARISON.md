# IOL distance comparison

| Distance | Role | Implemented |
|---|---|---|
| 40 cm | near | simulator preset; text |
| about 50 cm | EDOF near limit (doctor's reference) | lens text, summary, the EDOF bar in the preview art; the slider reaches 50 cm |
| 65 cm | intermediate (doctor's reference) | preset changed from 66 cm to **65 cm**; laptop scenario 65 cm |
| 6 m+ | far | preset |

- **Distances are educational examples,** not predictions of any patient's result.
- **No fourth "50 cm" preset button.** The scene has three object layers, so a fourth button would need a new object. Possible follow-up.

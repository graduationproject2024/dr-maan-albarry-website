# iTrace — asset and claim

- **Device:** iTrace by Tracey Technologies (Houston). The maker calls it a "5-in-1" device:
  - ray-tracing wavefront aberrometer;
  - autorefractor;
  - keratometer;
  - pupillometer;
  - Placido topographer.
- **What it does:** separates the cornea's contribution to vision errors from the lens's, and supports toric lens planning and alignment checks.

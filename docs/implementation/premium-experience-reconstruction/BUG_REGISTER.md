## BUG-19 — After tapping a header button the header stayed on screen for the rest of the page

| Field | Value |
|---|---|
| Severity | P3 |
| Page | All pages, phones and tablets |
| Device | 390×844, 320×640, 768×1024 |
| Language / theme | ar, en / light, dark |
| Reproduction | 1. Open the menu and close it by tapping Menu again 2. Swipe down the page |
| Expected | The header slides away while reading down |
| Actual (before the fix) | Header stayed visible (is-hidden false) because tap focus remained on the Menu button |
| Root cause | The scroll handler treated any focus inside the header as a reason to keep it shown; a tap leaves focus on the button. |
| Fix | Only keyboard focus (:focus-visible) keeps the header in place. Starting the 3D viewer brings the header back, because the header is meant to stay reachable while the viewer runs (found when the fix exposed a hidden header in persona F). |

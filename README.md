## 🌟 مميزات المشروع / Project Highlights

1. **تصميم طبي راقٍ وثنائي اللغة (Bilingual)**:
   - دعم كامل للغة العربية (RTL، الافتراضية) واللغة الإنجليزية (LTR) مع تبديل سلس ولحظي.
   - هوية بصرية متميزة تجمع بين درجات الياقوت الداكن (`#0A192F`)، العنابي الملكي (`#641B2D`)، الذهبي الدافئ (`#C5A46D`)، والبلاتيني السريري (`#F8F6F1`).
2. **محاكي الرؤية التفاعلي (Interactive Vision Simulator)**:
   - 3 سيناريوهات يومية حية: القيادة الليلية (طريق المطار بالمدينة)، قراءة الهاتف الذكي، وقراءة الكتب.
   - 4 حالات بصرية: إعتام المياه البيضاء، عدسة أحادية البؤرة (Monofocal)، عدسة ممتدة العمق (EDOF)، وعدسة ثلاثية البؤرة (Trifocal).
   - **شريط مقارنة تفاعلي مقسوم (Split-view Comparison Slider)** للمقارنة الحية بين الرؤية الطبيعية والمحاكاة.
   - تنبيهات وإخلاء مسؤولية طبية وسريرية واضحة.
3. **استبيان تثقيفي غير تشخيصي لخيارات العدسات (IOL Guide)**:
   - 4 أسئلة لمساعدة المريض على تحديد أولوياته ومحاور النقاش مع استشاري العيون.
   - حماية كاملة لخصوصية المريض (تخزين محلي بالمتصفح دون جمع بيانات شخصية أو إرسالها لواتساب).
4. **المكتبة الطبية الموثوقة (Medical Education Library)**:
   - 6 أدلة إرشادية تفصيلية ومحدثة للمرضى (المياه البيضاء، القرنية المخروطية، تثبيت القرنية CXL، الليزك، ورحلة المريض).
   - صندوق تنبيه العلامات الطارئة الحمراء (Emergency Red Flags).
   - إشراف ومراجعة طبية مثبتة باسم الاستشاري.
5. **الملف الشخصي والمسيرة المهنية (Physician Profile)**:
   - السيرة الذاتية، التعيينات الأكاديمية والقيادية، صور المؤتمرات والمجالس العلمية، وتقييمات حقيقية للمرضى بمغربي.
6. **معايير تحسين محركات البحث والذكاء الاصطناعي (SEO / GEO / AI-Ready)**:
   - بيانات منظمة دقيقة (JSON-LD Schemas): `Physician`, `MedicalBusiness`, `FAQPage`, `BreadcrumbList`.
   - ملف `robots.txt` وخريطة موقع `sitemap.xml` متعددة اللغات.
   - ملف `llms.txt` لتعزيز الظهور الدقيق في محركات الذكاء الاصطناعي (ChatGPT Search, Perplexity, Gemini).
   - ملف `manifest.webmanifest` لدعم تطبيقات الويب التقدمية (PWA).
